Welcome to ChEMBL 3D Explorer

This Django application provides two powerful tools for exploring molecular structures using SMILES notation:

🔬
ChEMBL Database Search

Query the ChEMBL database to retrieve comprehensive molecular information including:

  • Chemical identifiers and properties
  • Molecular formula and weight
  • Pharmacological data
  • Synonyms and structure identifiers

All searches are automatically saved to the database with timestamps for historical tracking.

Search ChEMBL →

🎨
3D Molecular Visualization

Generate high-quality 3D renderings of molecular structures using POV-Ray:

  • Ball-and-stick models
  • Optimized camera angles
  • High-resolution PNG output
  • Integrated with Open Babel

Requires obabel and povray to be installed on the server.

Generate 3D Image →

Example SMILES Strings:

  • Aspirin: CC(=O)Oc1ccccc1C(=O)O
  • Caffeine: CN1C=NC2=C1C(=O)N(C(=O)N2C)C
  • Benzene: c1ccccc1
  • Glucose: C(C1C(C(C(C(O1)O)O)O)O)O
